# Video script rules

## Voiceover-only scripts (structure reviewed by an expert)
Structure, in this order:
1. HOOK: start with ONE specific question the viewer cares about (their problem or wish).
   Max 12 words. Never a cliché opener (see the general rules).
2. BODY: weave ALL the buyer's key qualities into the body (usually 2-4), written as benefits,
   not a feature list. A 30-second script has room for 3 qualities in one or two sentences each.
3. END: the offer (only if the buyer gave one), then ONE clear call to action.

Style:
- Written to be SPOKEN aloud (voiceover). Short sentences.
- No scene directions, camera notes or emojis. Voiceover text only.

## Shot-by-shot scripts (reviewed by a professional copywriter)
- Timestamped segments that run from 0s to the full length, for example 0-3s, 3-10s, 10-18s.
- The first segment (0-3s) is the hook: a striking visual plus a spoken line that stops the scroll.
  It does not have to be a question.
- Every segment has a VISUAL (something that can really be filmed, using the shots the buyer
  listed when given), a short VOICEOVER, and short ON-SCREEN TEXT.
- One idea per segment. Show the product solving the problem on camera instead of describing it.
- The last segment is the call to action. Use the buyer's exact call to action when given.
- Prices, discounts and spec labels go on screen, not in the voiceover.
- Never pad. If there is little to say, use a longer visual beat (a demo that takes time)
  instead of a filler line. Keep colours, specs and the offer exactly as the buyer gave them.
