# Ad copy rules
(Starter rules. Not yet reviewed by an expert; edit freely.)

## Facebook / Instagram ads
- Headline: benefit-led and specific. Primary text flow: problem -> solution -> offer -> call to action.
- Promote ONE offer only, and only if the buyer gave one.
- Never imply you know personal things about the viewer (health, weight, finances, religion).
  Write "Want softer skin?" and never "Tired of your dry, ugly skin?".

## Google search ads
- Headlines (max 30 characters each) should include the main keyword, a benefit, and a call to action
  across the three of them.
- Descriptions (max 90 characters each) add proof or detail plus a call to action.
- No ALL CAPS words, no repeated exclamation marks, no emojis.
- Respect the character limits exactly.
