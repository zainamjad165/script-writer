# Social media caption rules
(Starter rules. Not yet reviewed by an expert; edit freely.)

- The first line is the hook. Only it shows before "see more", so make it count.
- One idea per caption. Keep paragraphs to 1-2 lines with line breaks for easy reading.
- Sound like a person, not a brand brochure.
- End with one clear action (order, DM, comment, visit the link).
- Hashtags only when requested: relevant and specific, on their own last line. No stuffing.
- Emojis only when requested, sparingly, never replacing words.
