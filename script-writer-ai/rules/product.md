# Product description rules
(Starter rules. Not yet reviewed by an expert; edit freely.)

- Title: clear and searchable (what it is + the key detail). No hype words.
- Open with the main benefit, then back it with specifics (material, size, use, what's included).
- Answer the questions a buyer would ask before buying.
- Keywords go in naturally. Never stuff or repeat them.
- Only state specs the buyer gave. If a detail is missing, leave it out; never guess.
- Highlights, when requested, are short and each carries one fact.
