# Script rules (edit this file to teach the AI your style)

## Structure (every script follows this order)
1. HOOK - start with ONE question the viewer cares about (their problem or wish). Max 12 words.
2. BODY - what the product offers: 2-3 qualities, written as benefits, not a feature list.
3. END - the offer (only if the buyer gave one), then ONE clear call to action.

## Style
- Written to be SPOKEN aloud (voiceover). Short sentences. Simple words.
- No filler like "in today's fast-paced world" or "look no further".
- Be concrete. "Keeps drinks cold for 24 hours" beats "great quality".
- Never invent facts, numbers, discounts, prices or guarantees the buyer did not give.
- Do not write scene directions, camera notes or emojis. Voiceover text only.
- Each version must use a DIFFERENT hook and a different angle.

## Things to avoid
- Fake urgency the buyer did not ask for.
- Exaggerated or medical claims.
- Repeating the product name more than twice.
